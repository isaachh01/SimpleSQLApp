API data

An API is a URL that returns data (usually JSON) instead of a normal web page. This page uses fetch() to ask an external sensors API for records, then shows the answer in two formats.

How to use this page

  1. Optionally change how many rows to request (limit).
  2. Click Load data — the browser sends a GET request to the API URL.
  3. Look at 1. Raw data — the JSON text exactly as it arrived.
  4. Look at 2. Rows — the same data array drawn as a table.

Base URL: https://digisolia3api.vercel.app/api/sensors

URL will appear here after you load.

1. Raw data

This is JSON.stringify of the whole response — good for seeing the shape: total, limit, offset, and data. 

Click “Load data” to fetch JSON.

2. Rows

Here we loop over the data array and build one table row per record — same idea as the Users page, but the source is an external API.
