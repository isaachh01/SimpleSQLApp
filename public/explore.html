Explore data

After you upload a spreadsheet on the Upload page, every column of every table in the database is available here. Pick a table, then a column, then a way to summarise it.

How to use this page

  1. Choose a table. The dropdown lists every table in the database (including any you uploaded).
  2. Choose a column. Columns marked number can use the number-only methods.
  3. Choose a display method. Each method runs a small SQL query — the SQL is shown with the result so you can see how it works.
  4. Click Show summary to send your choices to the server and draw the result.
