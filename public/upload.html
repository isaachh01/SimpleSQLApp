Upload Excel

Drag in an Excel file, check the suggested table setup, then create the table before importing the rows.

Instructions

  1. Drop a .xlsx file into the upload box.
  2. Check the table name, column names, data types, required fields, and primary key.
  3. Edit the CREATE TABLE SQL if you need foreign keys, then copy it into your assignment.
  4. Copy or download the INSERT SQL for your assignment whenever you like (before or after importing).
  5. Click Create table to add the empty table to SQLite.
  6. Click Import rows to fill the table with the Excel data.
